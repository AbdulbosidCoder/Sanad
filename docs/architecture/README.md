# Sanad — архитектурный пакет V1

Статус: **одобрено** (PR #1). Решения зафиксированы в [ADR](../adr/README.md).

Sanad — мультивендорный маркетплейс: приложение покупателя, панель продавца, панель администратора и поддержки. Стек: FastAPI, PostgreSQL, Redis, Celery, S3, Next.js, Docker. Архитектура: модульный монолит, API-first.
