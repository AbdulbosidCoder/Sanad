# ADR 0002: FastAPI вместо Django

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Нужен чистый API для трёх веб-приложений и будущих мобильных клиентов; HTML-шаблоны и встроенная админка Django не используются.

## Решение

FastAPI + Pydantic + SQLAlchemy 2 (async) + Alembic.

## Последствия

Автоматическая OpenAPI-документация и генерация клиента для фронтенда; явные зависимости, видно, откуда что берётся. Админку пишем сами (она всё равно нужна с RBAC и аудитом).
