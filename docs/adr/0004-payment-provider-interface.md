# ADR 0004: Платёжные провайдеры за интерфейсом

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

В V1 только тестовые платежи, позже Uzcard, Humo, Visa.

## Решение

Протокол `PaymentProvider` в модуле `payments`; V1 — `FakeProvider` с `is_test = true`, выключается в prod. Вебхуки с подписью, идемпотентность.

## Последствия

Новый провайдер — новый класс, логика заказов не меняется.
