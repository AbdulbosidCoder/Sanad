# ADR 0003: Родительский заказ и заказы продавцов

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Один checkout может содержать товары нескольких магазинов.

## Решение

`Order` (один на checkout, один платёж) → `SellerOrder` (по одному на магазин) → `OrderItem`. Статусы заказа и платежа хранятся раздельно.

## Последствия

Каждый продавец обрабатывает и возвращает только свою часть; частичные возвраты не ломают модель.
