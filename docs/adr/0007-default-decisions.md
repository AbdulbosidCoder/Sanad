# ADR 0007: Решения по умолчанию для пробелов в ТЗ

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

В ТЗ не определены перевод, поиск, комиссия, доставка, регистрация продавца и др.

## Решение

Принимаются значения из `docs/architecture/10-gaps-and-decisions.md`, раздел 10.1 (одобрено слиянием PR #1).

## Последствия

Любое решение можно пересмотреть отдельным ADR; таблица в 10.1 показывает цену изменения.
