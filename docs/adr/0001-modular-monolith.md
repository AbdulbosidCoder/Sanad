# ADR 0001: Модульный монолит вместо микросервисов

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Один разработчик, много связанных сценариев (checkout, остатки, платежи), которым нужны транзакции в одной БД.

## Решение

Один сервис `api` с 18 модулями в `backend/app/modules/`. Модули общаются через `service.py`/`events.py`, правила проверяются тестами.

## Последствия

Простой деплой и отладка. Модуль можно позже вынести в сервис, не трогая остальные. Нужно следить за границами — это делает CI.
