# ADR 0006: Наблюдаемость: request_id и модуль в каждой ошибке и строке лога

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Владелец проекта должен сам понимать, где произошёл сбой, и сообщать о нём одной строкой.

## Решение

Middleware присваивает каждому запросу `request_id` (заголовок `X-Request-Id`); роутер модуля помечает запрос своим именем. Ошибки — problem+json с `module`, `code` (`MODULE.CODE`), `request_id`. Логи — JSON с теми же полями.

## Последствия

По `request_id` из ответа находится весь путь запроса в логах. Внутренние детали ошибок не уходят клиенту.
