# ADR 0005: Токены: короткий access JWT + ротируемый refresh

- **Статус:** принято
- **Дата:** 2026-11-13

## Контекст

Нужна возможность отозвать сессию и подготовка к 2FA/passkeys в V3.

## Решение

Access JWT 15 минут, refresh в HttpOnly cookie с ротацией и обнаружением повторного использования; отдельная сущность `Session`; многошаговый вход.

## Последствия

Кража токена обнаруживается; V3 добавляет шаги входа без переделки остального.
