# Модуль `i18n`

Переводы контента (автоперевод описаний товаров на uz/ru/en, ручные правки).

## Связи

**Зависит от (вызывает их `service.py`):**
- `catalog`

**Используется модулями:**
- `search`

**Публикует события:**
- `TranslationReady`

**Слушает события:**
- `ProductCreated`
- `ProductUpdated`

**Таблицы:** `product_translations`, `category_translations`, `translation_jobs`

## Файлы

| Файл | Что внутри |
|---|---|
| `module.py` | Описание модуля и его связей (видно в `GET /api/v1/system/modules`) |
| `api.py` | HTTP-эндпоинты: принимают запрос, проверяют права, вызывают `service.py` |
| `service.py` | Бизнес-логика. Единственная точка входа для других модулей |
| `events.py` | События, которые модуль публикует и на которые подписан |
| `models.py`, `repository.py`, `schemas.py` | Появятся вместе с функциональностью |

## Где искать баг

Симптомы, которые обычно ведут сюда: нет перевода, перевод не обновился после правки, «съехал» язык.

В ошибке API и в логах ищите `"module": "i18n"` и `request_id`.
