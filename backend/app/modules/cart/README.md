# Модуль `cart`

Корзина покупателя (и гостя), сгруппированная по продавцам, с сегодняшними ценами и проверкой остатков.

## Связи

**Зависит от:** `catalog` (цены, можно ли купить), `inventory` (свободный остаток), `stores` (название магазина)
**Используется модулями:** `orders` (строки для checkout, очистка, возврат товаров в корзину)
**Таблицы:** `carts`, `cart_items`

## Эндпоинты

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/cart` | Корзина по магазинам: цена, сумма, `available`, `problem` (`unavailable` / `not_enough_stock`), `can_checkout` |
| POST | `/cart/items` | Добавить `{variant_id, quantity}`; если уже есть — количество складывается (до 99) |
| PATCH/DELETE | `/cart/items/{variant_id}` | Изменить количество / убрать |
| DELETE | `/cart` | Очистить |
| POST | `/cart/merge` | После входа: гостевая корзина (`X-Cart-Token`) переходит в корзину пользователя |

Гость шлёт `X-Cart-Token` — случайная строка от 32 символов, её генерирует и хранит фронтенд. В БД — только SHA-256 токена.

## Где искать баг

Не добавляется товар: `CART.UNAVAILABLE` (товар снят с продажи или магазин приостановлен), `CART.NOT_ENOUGH_STOCK`. Ищите `"module": "cart"`.
