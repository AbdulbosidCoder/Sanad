# Модуль `analytics`

Аналитика продавца: продажи, выручка, просмотры, конверсия, бестселлеры.

## Связи

**Зависит от (вызывает их `service.py`):**
- `orders`
- `engagement`
- `search`

**Используется модулями:**
- —

**Публикует события:**
- —

**Слушает события:**
- `OrderPlaced`
- `ProductViewed`
- `SearchPerformed`

**Таблицы:** `seller_daily_stats`, `product_daily_stats`

## Файлы

| Файл | Что внутри |
|---|---|
| `module.py` | Описание модуля и его связей (видно в `GET /api/v1/system/modules`) |
| `api.py` | HTTP-эндпоинты: принимают запрос, проверяют права, вызывают `service.py` |
| `service.py` | Бизнес-логика. Единственная точка входа для других модулей |
| `events.py` | События, которые модуль публикует и на которые подписан |
| `models.py`, `repository.py`, `schemas.py` | Появятся вместе с функциональностью |

## Где искать баг

Симптомы, которые обычно ведут сюда: цифры в дашборде продавца не сходятся или не обновляются.

В ошибке API и в логах ищите `"module": "analytics"` и `request_id`.
