# Модуль `analytics`

Аналитика для кабинета продавца за выбранный период (`?days=1..365`, по умолчанию 30).
В V1 считается прямо по исходным таблицам; суточные агрегаты появятся, когда данных станет много.

## Связи

**Зависит от:** `orders` (продажи), `engagement` (просмотры, избранное), `catalog` (товары
магазина), `inventory` (что заканчивается), `reviews` (рейтинг магазина), `stores` (доступ)

Право: `store.analytics_read` (владелец, менеджер; не обычный сотрудник).

## Что считается

- **Выручка** — сумма оплаченных и не отменённых/не возвращённых заказов магазина;
  **комиссия** — зафиксированная при оформлении; **net** = выручка − комиссия.
- **Конверсия** — заказы / уникальные зрители товаров магазина (просмотр считается раз в 30 минут).
- **change** — сравнение с предыдущим периодом такой же длины (`null`, если сравнивать не с чем).
- **by_day** — точки для графика за каждый день периода (пустые дни = 0).

## API

| Метод | Путь | Что |
|---|---|---|
| GET | `/seller/analytics/summary?days=` | Итоги, статусы заказов, мало на складе, рейтинг, график |
| GET | `/seller/analytics/products?days=&sort=revenue\|units\|views\|conversion` | По каждому товару |
