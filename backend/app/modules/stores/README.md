# Модуль `stores`

Магазины, заявки продавцов, сотрудники магазина.

## Связи

**Зависит от (вызывает их `service.py`):**
- `identity`
- `audit`

**Используется модулями:**
- `catalog`
- `orders`

**Публикует события:**
- `SellerApplicationSubmitted`
- `StoreApproved`
- `StoreSuspended`

**Слушает события:**
- —

**Таблицы:** `stores`, `store_memberships`, `seller_applications`

## Файлы

| Файл | Что внутри |
|---|---|
| `module.py` | Описание модуля и его связей (видно в `GET /api/v1/system/modules`) |
| `api.py` | HTTP-эндпоинты: принимают запрос, проверяют права, вызывают `service.py` |
| `service.py` | Бизнес-логика. Единственная точка входа для других модулей |
| `events.py` | События, которые модуль публикует и на которые подписан |
| `models.py`, `repository.py`, `schemas.py` | Появятся вместе с функциональностью |

## Где искать баг

Симптомы, которые обычно ведут сюда: продавец не видит панель, заявка не одобряется, сотрудник не видит магазин.

В ошибке API и в логах ищите `"module": "stores"` и `request_id`.
