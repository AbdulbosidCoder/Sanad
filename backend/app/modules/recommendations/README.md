# Модуль `recommendations`

Главная страница и подборки. В V1 считается «на лету» из просмотров, избранного и продаж
(кэш-таблица и обученная модель — V2).

## Связи

**Зависит от:** `catalog` (карточки, категории, бренды), `engagement` (просмотры,
избранное), `orders` (продажи, купленное покупателем)

## Блоки

| key | Откуда |
|---|---|
| `for_you` | Только вошедшим: «с этим смотрят» для недавно просмотренных / избранных / купленных, дополняется теми же категориями; уже купленное и просмотренное исключено |
| `new` | Новые товары в наличии |
| `sale` | Товары со старой ценой выше текущей |
| `trending` | Больше всего просмотров за 7 дней |
| `bestsellers` | Больше всего продано за 7 дней (оплаченные, не отменённые) |
| `also_viewed` | Страница товара: что открывали те же зрители за 30 дней |
| `similar` | Страница товара: та же категория и бренд, потом просто категория |

Пустые блоки не возвращаются. Заголовки на языке запроса (`?lang=`).

## API

| Метод | Путь | Что |
|---|---|---|
| GET | `/home` | Категории, бренды (по числу товаров), блоки |
| GET | `/products/{product_id}/recommendations` | `also_viewed`, `similar` |
