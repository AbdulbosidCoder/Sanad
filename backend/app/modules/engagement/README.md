# Модуль `engagement`

Избранное и просмотры товаров (основа для «Сейчас смотрят», «Для вас», «С этим товаром
смотрят» и аналитики продавца).

## Связи

**Зависит от:** `catalog` (карточки, проверка, что товар виден покупателю)

**Используется:** `recommendations`, `analytics` · **Публикует:** `ProductViewed`

**Таблицы:** `favorites`, `product_views`

## Правила

- В избранное можно добавить только видимый покупателю товар; повторное добавление — не ошибка.
- Просмотр считается один раз на зрителя за 30 минут. Зритель — пользователь, а гость —
  хеш его `X-Device-Id` (случайный id, который хранит клиент) или IP.

## API

| Метод | Путь | Кто | Что |
|---|---|---|---|
| GET | `/me/favorites` | покупатель | Избранное, новые сверху |
| GET | `/me/favorites/flags?product_id=…&product_id=…` | покупатель | «Сердечки» для списка карточек |
| PUT / DELETE | `/me/favorites/{product_id}` | покупатель | Добавить / убрать |
| POST | `/products/{product_id}/views` | все | Открыли страницу товара |
| GET | `/me/viewed` | покупатель | Недавно просмотренные |
